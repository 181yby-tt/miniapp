# 课序小程序 · 微信开发者工具「上线与测试」指南

本文面向**已经在本地跑通后端 + 小程序**的你，手把手说明如何：
1. 用微信开发者工具导入并调试小程序；
2. 在真机（手机微信）上预览/调试；
3. 把后端接口接到「合法域名」；
4. 上传代码 → 提交审核 → 正式发布。

1. 打开微信开发者工具 → 选择「**小程序**」→「**导入项目**」。
2. 目录：选择 `E:\181app\kexu\miniprogram`（即含 `app.json` 的那一层）。
3. AppID：选择「**填写 AppID**」并填入 `wxe660278769911dc3`（已预填，可直接用；若显示 touristappid 请手动改成你的）。
4. 后端服务：勾选「**不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书**」这一项（在「详情 → 本地设置」里），这样本地 `http://localhost:3000` 才能被小程序访问。
5. 点击「导入」，模拟器会加载出登录页。

### 本地联调登录
- 项目里 `utils/request.js` 的 `BASE_URL` 目前是 `http://localhost:3000`，正好指向你本地后端。
- 在模拟器里用学生账号登录：`20260108 / 123456`（教职工后台 `admin / demo123456`）。

## 三、真机预览 / 真机调试

模拟器只能验证 UI 与逻辑，**真机**才能验证微信登录、支付、订阅消息等真实能力。

| 方式 | 适用 | 后端如何可达 |
|---|---|---|
| 模拟器 | 日常开发 | `localhost:3000`（需勾「不校验合法域名」） |
| **真机预览**（点「预览」生成二维码，手机扫） | 快速看效果 | 手机**无法直接访问** localhost。需后端部署到公网 HTTPS 地址，并把域名加入白名单（见第四节） |
| **真机调试**（点「真机调试」） | 真机排错 | 同上，依赖公网 HTTPS 后端 |

**结论**：要在手机上完整跑通（尤其是 `wx.login` → 后端换 `openid`），请把后端部署到一个**已备案的 HTTPS 域名**下，再配置合法域名白名单。本地 `localhost` 仅供模拟器联调。

## 四、配置服务器域名（request 合法域名）

小程序正式包**只许请求白名单内的 HTTPS 域名**（本地「不校验」仅对开发者工具/模拟器生效，对线上包无效）。

1. 登录 https://mp.weixin.qq.com → 你的小程序 → **开发 → 开发管理 → 开发设置 → 服务器域名**。
2. 在 **request 合法域名** 里添加你的后端地址，例如：
   ```
   https://api.kexu.example.com
   ```
   （必须是 HTTPS，且域名已完成 ICP 备案；端口只能是 443/80，不能带自定义端口。）
3. 修改 `miniprogram/utils/request.js` 的 `BASE_URL` 为上面这个域名（去掉 `/api` 前的部分，接口路径保持不变）：
   ```js
   const BASE_URL = 'https://api.kexu.example.com';
   ```
4. 同样把 `miniprogram/app.js` 里 `globalData.baseUrl` 同步改掉。
5. 改完后在开发者工具点「**刷新**」或重新编译。

> 上传（上传代码）和真机预览时，若仍用 localhost，真机一定失败；务必先切到白名单 HTTPS 域名再上传。

## 五、上传代码

1. 在开发者工具顶部点「**上传**」。
2. 填写**版本号**（如 `1.0.0`）和**项目备注**（如「校本选课排课学生端首批」）。
3. 上传成功后，代码进入 mp 后台的「**开发版本**」。

> 上传前请确认：`BASE_URL` 已是白名单 HTTPS 域名、且没有残留 `console.log` 敏感信息、`project.config.json` 的 `urlCheck` 不影响线上（线上强制校验域名）。

## 六、提交审核 → 发布

1. 登录 mp 后台 → **管理 → 版本管理**。
2. 在「开发版本」里点「**提交审核**」。
3. 填写审核信息：
   - **功能页面**：填 `pages/hall/hall` 等核心页路径；
   - **服务类目**：选「教育 > 学校/教育服务机构」之类（需与主体一致）；
   - **测试账号**：务必提供测试用学生账号（如 `20260108 / 123456`）与教职工账号（`admin / demo123456`），否则审核会被打回；
   - **隐私说明**：本项目会获取微信 `openid`（用于登录与绑定），需在「**用户隐私保护指引**」中勾选「_openid_」相关说明并发布。
4. 审核周期通常 1–7 天。被驳回常见原因：
   - 未配置隐私指引 / 类目不符；
   - 无测试账号或登录后页面空白；
   - 实际功能与所填类目不符；
   - 请求了非白名单域名。
5. 审核通过后，在「版本管理」里点「**发布**」即正式上线。

## 八、常见问题速查

| 现象 | 排查 |
|---|---|
| 模拟器白屏 / 请求失败 | 检查后端是否在跑；确认已勾「不校验合法域名」；`BASE_URL` 是否为 `localhost:3000` |
| 真机预览登录失败 | 后端未部署到 HTTPS 公网 / 域名未加白名单；或 AppID 与 secret 填反 |
| `wx.login` 返回 code 但后端报 `WECHAT_LOGIN_FAILED` | AppSecret 错误、AppID 与 secret 不匹配、或该 code 已过期（5 分钟/单次） |
| 审核被拒：无测试账号 | 在审核资料里提供 `20260108/123456` 与 `admin/demo123456` |
| 审核被拒：隐私 | 到 mp 后台补充「微信 openid」隐私指引并重新提审 |
